## 💎 О проекте

**AZ•ART Interactive Gambling Club** — это коллекция веб-симуляторов классических игр казино (Poker, Blackjack, Roulette) премиум-класса. Бренд сочетает в себе атмосферу элитных закрытых клубов, математически точную симуляцию механик и глубокую визуально-звуковую проработку.

Имя бренда символизирует синергию предельного риска (**Азарт**) и эстетического совершенства (**Art**).

---

## 🔱 Презентация логотипов и бренд-системы

Брендинг разработан в векторном формате (SVG) высокой точности с применением многослойных градиентов литого золота, чеканки и текстур бархатного изумруда.

### 1. Круглая гербовая эмблема (Crest / Seal)
Предназначена для аватарного формата, иконок приложений, рубашек карт, игровых фишек и центрального оформления игрового сукна.

* **Символизм:** В верхнем сегменте размещен пиковый знак (♠) с выгравированной буквой **A**, образующий геральдическую корону.
* **Баланс:** Монументальный блок **AZ • ART** выверен относительно центрального кристалла-разделителя.

### 2. Прямоугольный плашечный логотип (Wide Banner)
Используется в шапках сайтов (Header), мобильных интерфейсах, рекламных баннерах и промо-материалах.

## 🎲 Игры в составе клуба

1. **♠️ 5-Card Draw Poker** — классический покер с обменом карт, продвинутой оценкой комбинаций и аутентичным управлением ставками.
2. **♥️ Blackjack (21)** — блэкджек с автоматизированным дилером, сплитом и точной математикой выплат.
3. **♦️ European Roulette** — реалистичная симуляция колеса рулетки с анимацией движения шарика и интерактивным полем ставок.

## 🛠 Технологический стек

* **Frontend:** Vanilla HTML5 / CSS3 (Custom Properties, Flexbox & Grid).
* **Graphics & UI:** Чистый векторный SVG (Defs, Linear/Radial Gradients, DropShadow & Emboss filters).
* **Mechanics:** Pure JavaScript (ES6+) для расчета весовых коэффициентов и логики дилера.
* **Audio System:** Web Audio API для процедурного воспроизведения звуков фишек, карт и вращения колеса.
